# 角色照片说明

## 添加角色照片

请在这个文件夹中添加角色照片，文件命名规则如下：

- `lin_shen.png` - 林深
- `gu_yuan.png` - 顾远
- `zhao_tai.png` - 赵泰
- `xia_he.png` - 夏禾
- `su_xiao.png` - 苏晓

## 图片要求

- 格式：建议使用 PNG 或 JPG
- 尺寸：建议 300x400 像素或类似比例
- 文件名必须与 roles.json 中配置的一致
- 如果照片不存在，会显示默认占位图 👤

## 注意事项

1. 请确保文件名完全匹配，包括大小写
2. 照片会在角色选择界面显示
3. 照片宽度固定为 150 像素
4. 可以随时更换照片，无需重启应用
